# TNB
TNB - Telegram Notification Bot based on information from Liquipedia.net

Used:
aiogram, PostgreSQL, SQLAlchemy, BeatifulSoap4, Liquipedia API

Pet project
Which gets info from API (available only parse no post/get) and presents information about tournaments and games in Telegram. Using Telegram API made simple and easy to use interface in dialog and notification 1 hour before and when starts
